# Travel Weather Tool

An application that shows the weather and country information for any city

## What It Does

- Retrieves JSON data to include formatted information of:
	- the city
	- Weather in the city along with additional information
		- longitudes, latitudes, wind speed, temperature, etc.

## Features:
	- API integration & API Chaining
	- Error handling
	- JSON response processing

## Setup

```bash
pip install requests python-dotenv
    OPENWEATHER_API_KEY in .env file
```

## Usage

```python
day3_travel_info.py

```

## Sample Output

```
=== Lagos, NG ===
Temperature    : 29.86C
Condition      : Broken Clouds
Humidity       :70%

```
